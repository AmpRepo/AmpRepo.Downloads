AmpRepo Pilot

Installing

The app needs no separate .NET install. It is not yet code-signed, so Windows and macOS ask you to confirm the first time you open it.

Windows

Download the .msi and run it. Windows SmartScreen warns because the installer is unsigned: click More info → Run anyway. It installs for all users into C:\Program Files\AmpRepo\AmpRepo.Pilot, so Windows asks for admin approval. A newer version upgrades an older one in place.

macOS

Download the .zip for your Mac, open it, and drag AmpRepo Pilot into Applications. The first launch is blocked ("Apple could not verify…") because the app is not signed with an Apple Developer ID. To allow it once: try to open it, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. Or, in Terminal:

xattr -dr com.apple.quarantine "/Applications/AmpRepo Pilot.app"

The device needs no driver. To update, replace the app in Applications. Firmware updates from the app do not work on macOS yet.

Linux (x86_64)

Download the .AppImage, make it executable and run it:

chmod +x AmpRepo.Pilot-*-x86_64.AppImage
./AmpRepo.Pilot-*-x86_64.AppImage

To let the app open the device's USB port, download 60-amprepo-pilot.rules and install it once, then unplug and replug the device:

sudo cp 60-amprepo-pilot.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger

Or add yourself to the dialout group (sudo usermod -aG dialout $USER) and log out and back in. If the AppImage does not start on a system without FUSE, run it with --appimage-extract-and-run. To update, download the new AppImage and delete the old one.
